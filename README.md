## Особенности
- Данные хранятся, исключительно, на устройстве пользователя, в зашифрованном виде.
- Desktop-приложение (ожидается поддержка мобильных устройств).

## Предварительные требования
- Python 3.13+
- Pip 24.2+
- Git 2.45+
- SQLite 3.45+
